# QBF Consulting website

Official website for **QBF Consulting LLP**.

**Live site:** https://qbfconsulting.digital

## About this repository

This repository hosts the public QBF Consulting website using GitHub Pages.

The site is intentionally simple and dependency-free:

- static HTML
- no application framework
- no external build system
- GitHub Pages deployment from `main`

## Repository structure

- `index.html` — public website
- `assets/` — approved web brand assets
- `CNAME` — custom domain configuration for `qbfconsulting.digital`
- `.nojekyll` — disables Jekyll processing

## Deployment

`main` is the production branch.

Changes should be developed on a separate branch, reviewed through a pull request, and merged into `main`. GitHub Pages deploys the resulting site automatically.
